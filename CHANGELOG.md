# Changelog

## 3.0 — новый интерфейс и обход белых списков (OpenFlux)

### Интерфейс и GUI — переписан с нуля
- Нативные XML-экраны заменены WebView-стеком (`assets/index.html`, `app.js`, `bypass.js`,
  локальный Tailwind, офлайн), состояние — через мост `window.Bridge`.
- Нижняя навигация на три вкладки: «Проверка», «Обход», «Настройки».
- Главный экран: облачко-статус с цветовой кодировкой, круглая кнопка-триггер,
  чипы «Трафик» и «Время», двухколоночный список сайтов.
- **Добавление/удаление сайтов прямо из пинговалки**: «+» в шапке колонки открывает
  модалку со списком, вводом с валидацией домена и защитой от дублей, удалением с анимацией.
- Инлайн-статусы доменов во время проверки: `OK` / `RESET` / `--` / `STOP`.
- Экран настроек (авто-проверка, интервал, списки для обхода) и экраны обхода с нижними
  шторками и свайпом.
- Новая иконка приложения.

### Вырезано из интерфейса как ненужное
- Экран статистики с графиком (`ChartView`, `StatisticsActivity`) — история пишется в БД,
  экрана с графиком нет.
- Настройки окна по времени: пресеты 15/20/45/60 минут и часы «с / по».
- Спиннер «сайт разработчика» в футере.

### Добавлено
- Раздел «Обход» с двумя режимами: **Клиент** и **Выходная нода**.
- VPN-клиент на ядре OpenFlux (транспорт Телемост): режимы «весь трафик» и
  «только выбранные сайты», выбор приложений, показ внешнего IP.
- **Выходная нода**: телефон раздаёт интернет другим устройствам; QR-код рисуется ядром,
  есть «Поделиться ссылкой» и «Копировать ссылку».
- Раздача уже добавленного подключения в один тап; если подключений нет — кнопка
  «Добавить ноду» с экраном настроек (название, конференция, ключ, генератор ключа).
- Сканирование QR для добавления подключения (`zxing-android-embedded`).
- Предупреждение при запуске проверки с включённым VPN: тестер соврёт про белые списки,
  с кнопкой принудительного замера.
- Сохранение настроек ноды и профилей подключений в `SharedPreferences`.

### Изменено
- Экран «Обход» переведён на UI из макета: сегментированный переключатель режимов,
  кнопки питания с индикацией, сворачиваемый блок «Сведения».
- Добавление подключения — **только** через QR.
- Иконка приложения заменена (глобус со щитом).

### Исправлено
- Кнопка питания клиента не обновлялась при включении туннеля: состояние теперь
  опрашивается раз в секунду, есть промежуточное состояние «Подключение…».
- Восстановлены модальные окна управления списками сайтов.

### Технически
- `BypassNodeService` (foreground service, `specialUse`) для режима ноды.
- `BypassService` (VpnService) для клиента; исключение собственного пакета из туннеля,
  чтобы не зацикливать транспорт.
- `BypassPrefs` — хранилище профилей, режима, списков сайтов/приложений и настроек ноды.
- Ядро: `openflux.aar` (gomobile, `arm64-v8a`), `minSdk 26`.
